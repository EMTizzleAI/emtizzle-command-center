# EMTizzle AI // Command Center
Responsive installable PWA launcher for Codebabe, EMTizzle, Virion Network, Goblin Network, Pontoufle Intercom and Glitchbot.

## Run locally
`python3 -m http.server 8080`

## Configure links
Edit the `apps` array at the top of `app.js`. Entries marked `local:true` intentionally show as local nodes until their desktop/LAN launch targets are wired in.

## Deploy
Static site: deploy this directory to Vercel or any static host.
